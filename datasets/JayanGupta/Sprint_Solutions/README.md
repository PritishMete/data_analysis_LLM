# Sprint analysis datasets

This folder contains datasets used across SQL, Python analysis, Power BI, supervised learning, unsupervised learning, neural-network, and deep-learning exercises.

The files support restaurant, movie, book, churn, review, product, vehicle, customer, travel, music, and other business-analysis tasks. Typical requirements include schema profiling, data cleaning, joins, filtering, grouping, aggregation, feature engineering, visualization, model evaluation, and report generation.

The `datasets/OpenBook` files are sharded portions of a large book or text dataset and are intended for chunked ingestion or sampling workflows.
