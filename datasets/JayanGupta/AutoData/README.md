# AutoData sample datasets

These files support general-purpose data analysis demonstrations in the AutoData project.

- `customer_churn.csv` supports churn-rate, customer-segment, and retention analysis.
- `sales_data.csv` supports revenue, product, time, and regional performance analysis.
- `web_traffic.csv` supports visits, source, conversion, and traffic-trend analysis.

Typical requirements are schema inspection, missing-value checks, grouping, filtering, aggregation, trend analysis, and visual summaries.
