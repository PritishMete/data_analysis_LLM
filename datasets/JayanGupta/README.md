# Public datasets collected from JayanGupta repositories

This folder contains CSV files collected from the public repositories on
`https://github.com/JayanGupta?tab=repositories`.

The first directory level is the source repository. Paths below that level
match the source repository path, so files with the same filename remain
separate.

The collection currently contains 352 CSV files totaling approximately 1.71
GB. The large `Notes/datasets/OpenBook/` and
`Sprint_Solutions/datasets/OpenBook/` directories contain the source shards.

The trainer repository was not modified.
