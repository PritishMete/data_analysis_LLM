# Analytics learning datasets

This folder contains datasets used with the author's data-analysis and data-science learning notes.

The files cover vehicles, customers, books, retail and sales activity, movies, restaurants, jobs, music, travel, churn, and other analytical subjects. They support schema discovery, cleaning, SQL practice, exploratory analysis, visualization, supervised learning, clustering, NLP, and dashboard preparation.

The `datasets/OpenBook` files are sharded portions of a large book or text dataset and are intended for chunked ingestion or sampling workflows.
